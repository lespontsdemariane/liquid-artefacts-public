# liquid-artefacts-public

The shared, open-source, community repository for **artefacts** generated by [liquid-os](https://github.com/lespontsdemariane/liquid-os).

## What is an artefact?

In liquid-os, an *artefact* is a catalogue object produced by the platform's skill-chain compilers: a **schema**, **permission**, **task**, **workflow**, or **view**. Artefacts are generated by AI, then published through a human-signed publication gate (or auto-published for lower-risk tiers) before they become part of an instance's live catalogue.

Agentic RAG only ever *combines* what is already published — it never generates a new artefact. Generation is reserved for the compiler skills themselves.

## What lives in this repo

This repo is the default public destination for **generated task code** (the Python task functions and their tests produced by the task compiler). It is:

- **Pre-seeded** into every liquid-os instance's registry of artefact repositories, out of the box — this is the default repository artefacts are synced against.
- **Read-only by default** — no write credential is configured until an admin deliberately opts in.
- **Opt-in only for writes, never a silent default** — pushing here for a given task is an explicit, per-compilation choice. This repo must never become an accidental destination for a company's proprietary business logic; instances that want to keep generated code private configure their own private repository instead (see [liquid-artefacts-private](https://github.com/lespontsdemariane/liquid-artefacts-private) for the pattern).

## Contributing

Anything merged here is shared with every liquid-os instance that opts in, so an artefact is only worth publishing publicly when it is genuinely reusable beyond the instance that produced it: a generic transformation, a widely-applicable validation rule, a standard integration. Business logic specific to one organisation belongs in that organisation's own private repository.
